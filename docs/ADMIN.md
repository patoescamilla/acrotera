# Uso del panel de administración

El panel está en `/admin` y solo entra un usuario con rol `admin` (ver el README para crearlo).

**Agregar un producto:** Productos → Nuevo producto → llena la ficha → Crear. El producto se crea como borrador. Después se suben las fotos arrastrándolas al recuadro (la primera es la portada y se reordenan con las flechas) y se cambia el estado a *Publicado*.

**Marcar un pedido como entregado:** Pedidos → abre el pedido → Cambiar estado → Entregado.

**Cambiar el anuncio de arriba, el titular de la portada o el monto de envío gratis:** Textos. El monto de envío se guarda en un solo lugar y de ahí lo leen el cobro, el resumen del carrito y el anuncio, así que no pueden contradecirse. En el texto del anuncio, `{envio}` se sustituye por el monto vigente.

**Cambiar las fotos grandes del sitio:** Portada. Ahí están la imagen principal, los bloques de categoría y las imágenes de Interiorismo, Aromas y Nosotros. Cada ranura indica para qué sirve. Si una queda vacía, esa zona muestra un fondo de color en lugar de una imagen rota.

**Quitar un producto de la tienda sin perder el historial:** cambia el estado a *Archivado*. Eliminar borra el producto y sus fotos de forma permanente.
